# 🎨 Colourful Files for Obsidian
Transform your Obsidian sidebar from a uniform, monochrome list into a highly structured, vibrant visual workspace. **Colourful Files** breaks away from boring file trees by injecting a premium, high-density palette matrix directly into your native folder options. 

Whether you want to color-code your project hierarchies, instantly highlight high-priority notes, or design a beautiful custom aesthetic, this plugin makes navigation completely effortless.

---

## ✨ Core Features

### 📦 Symmetrical 64-Color Palette Matrix
* **The Hook:** A hand-curated library of 64 stunning colors organized into an elegant, space-saving 8x8 grid dashboard.
* **The Benefit:** Instantly tag items using professional pastels, deep ocean blues, vibrant greens, eye-catching neons, or high-contrast earth tones. No clunky menus—just quick visual styling.

### 🌊 Intelligent Color Cascading
* **The Hook:** Smart structural inheritance logic for your vault tree layouts.
* **The Benefit:** Apply a color to a parent folder, and watch all nested sub-directories and individual files automatically inherit that tone with calculated, sleek transparency overlays. Style an entire project tree in a single click.

### ✨ Kinetic Hover Feedback Engine
* **The Hook:** Responsive micro-interactions built right into the interface.
* **The Benefit:** Swatches feature fluid visual feedback under your cursor, popping with smooth elastic scaling, elevated layer depth, and a subtle radial glow to make custom styling feel incredibly premium.

### 🎨 Custom Hex Input Engine
* **The Hook:** Total custom brand integration.
* **The Benefit:** Need a specific shade that isn’t in the 64-color grid? Use the integrated text prompt to type in any custom hex code or standard CSS keyword for unlimited personal styling.

### ⚡ Zero-Footprint Performance
* **The Hook:** A lightweight, highly optimized rendering engine built for scale.
* **The Benefit:** Engineered for zero lag. It runs flawlessly on desktop and mobile vaults alike, ensuring completely smooth browsing even if your vault contains tens of thousands of files.

---

## 🛠️ Interface Mechanics

We designed this plugin to keep your workspace completely clean. Instead of cluttering your right-click context menus with massive, text-heavy list items, **Colourful Files** condenses its massive custom library into a tight, highly organized grid layout:

| Layout System | Grid Footprint | Interactive State | Persistence |
| :--- | :--- | :--- | :--- |
| **CSS Grid (8x8)** | Ultra-Compact 18px Swatches | 3D Floating Pop on Hover | Asynchronous Local Data Storage |
